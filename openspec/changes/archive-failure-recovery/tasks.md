## 2. Recovery offer — `mods/openspec/main.js`

- [x] 2.1 Add the shared key `"openspec.archive-failed"` as a map keyed by panel id — `{ [panel]: { panel, name, detail, root, on, space, seq, at } }` — written by the failure tail before `notify` (the `OPENS` / `openRequests` pattern, 64–73 and 295–313); readers drop records older than 60 seconds (`OPEN_AGE_MS`, 71). Beside it name the overlay-id key: `const DIALOG = "openspec.archive-dialog"`, holding the newest dialog's overlay id (`openOverlay`'s return, d.ts 22554).
- [x] 2.2 Add `knownAgents` to the `herdr` import (19). Add an `archiveFailed` mode in `init`, checked after the `menuFor` check (638) and the `file` check (644): a minimal view with no polls and no folder watch, keeping its `seq` and `panel` from props, rendering the title "Archive failed", the error line, "Archive <name> using AI?", and buttons **Archive using AI** / **Dismiss**; every button ends with `closeOverlay(props().overlay)`. That view takes the keyboard itself, as `menuView` does — `init` calls `this.handle.focus()` and its render root adds `.track_focus(this.handle)` — because an overlay does not focus on its own and the `escape` handler below would never fire. Add the matching branch in `render()` beside the `menuFor` / `file` checks (1479–1480) and before the list body, so the dialog never reaches code that reads `this.changes` / `this.context` or calls `refresh`. That branch's key handler gets an `escape` handler (the `menuView` pattern, 1336) that deletes this copy's record from the shared map behind the `seq` check below and then calls `closeOverlay(props().overlay)`: Esc is closed host-side (d.ts 22556, "Esc closes the top dialog or popup"), so no button handler ever runs for it. The view's `close()` deletes this copy's record from the shared map too, but only as insurance and only while the stored `seq` still matches its own, so a newer failure's record is not dropped — `close()` is "Application root only: one final call when the host closes this copy" (d.ts), and this repo only ever receives it for pane copies (925–942), so a dismissed dialog cannot rely on it.
- [x] 2.3 Open the dialog from the failure tail with `setShared(DIALOG, openOverlay({ mod: "openspec", props: { archiveFailed: { panel: this.panelId, name, detail, root, on, space, seq } }, kind: "dialog", modal: true, width: 420 }))`, closing the id already in `DIALOG` first (shared overlay id, newest wins). Put that open-and-store in one small helper, because 2.5 needs the same sequence.
- [x] 2.4 In the dialog's `init`, spawn `knownAgents({ on })` and set `this.dispatched = false`. On **Archive using AI**: return at once when `this.dispatched` is set, else set it, then, when an installed agent exists, `run("tab.new", { space, folder: root, argv: agent.run, task: \`/opsx-archive ${name}\` })`; otherwise `cx.write_to_clipboard(\`/opsx-archive ${name}\`)` plus a `notify` reading "Copied — paste it into your agent". Wrap those host calls in a `try/catch` whose `catch` takes the clipboard path (copy plus the "Copied" toast), so a throwing `run` still leaves a way to recover. Delete this copy's record from the shared map only after one of those paths has run, behind the `seq` check, then `closeOverlay(props().overlay)`. Dispatching before closing keeps the host calls on a live view, the same rule `menuView` follows (1328); deleting after them means a throw cannot leave the dialog open over a spent button and a vanished record. While `knownAgents` is still pending, or when it rejects, treat the agent list as empty and use the clipboard fallback. **Dismiss** deletes this copy's record behind the same `seq` check and closes; `close()` deletes it again only as insurance (2.2).
- [x] 2.5 Add `action: { name: "openspec.archive-ai" }` to the failure `notify` (1153) and an `"archive-ai"` branch in the list-mode `nextCommand` loop (694–702) that opens the same dialog for the matching `panelId`, mirroring `acceptOpen` (771–777) and reusing 2.3's helper — so the id already in `shared(DIALOG)` is closed before the new one opens, and a toast action pressed while the dialog is up replaces it rather than stacking a second modal. The branch does nothing when no record is left for that copy — already handled, or older than a minute.
