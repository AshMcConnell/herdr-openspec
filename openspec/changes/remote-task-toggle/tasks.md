## 1. Remote toggle write

- [x] 1.1 In `mods/openspec/main.js`, add module-level helpers beside `toggled`: `occurs(text, needle)` counting literal substring occurrences (split/join, never a regex — task text can hold regex characters), and `flipPair(body, line, next)` returning `{ old, neu }` — the clicked line's exact bytes in `body` and in `next`, trailing `\r` kept and nothing added (one line: no trailing `\n`, no neighbouring context), using the same 0-based `split("\n")` index `toggled` uses — or `null` when the two lines differ beyond the checkbox. Refuse without writing when `old` is not unique in `body` ("the task's line is not unique in tasks.md"); there is no widening retry, and the CLI's all-or-none guard backs the refusal up. A pair whose `old` and `neu` are the same bytes changes nothing: hand it back unchanged, so `writeFlip` accepts the file already holding the asked state with no edit and no verify.
- [x] 1.2 Add `writeFlip(path, body, next, line, task, to)` on the panel object, plus an `exitDetail(r)` helper for readable command errors. With no `this.on`: `await writeTextFile(path, next, body); return next;` — the existing call verbatim. With `this.on`: build the pair (1.1), run `exec("herdr-core", ["file", "edit", path, "--old", old, "--new", neu], { cwd: this.root, on: this.on })` (herdr-core running on the machine — `exec`'s `on` routes the whole process there, `this.root` is its cwd and no `--on` is needed); a non-zero exit throws `exitDetail(r)` — the last non-empty stdout/stderr line parsed as JSON becomes `herdr-core: <error.message> (<hint>)`, otherwise the raw line cut to 300 chars like the archive button's detail. Then `readTextFile(path, { on: this.on })` and accept only when `reread.split("\n")[line] === next.split("\n")[line]` — the clicked line holds the flipped text — returning the re-read; anything else throws ("tasks.md is gone" when the re-read is null, "the write did not land as asked" when the line does not match). When the built pair has `old` equal to `neu`, it returns the read text as settled with no edit and no verification.
- [x] 1.3 Rewire `toggle()`: drop `this.on` from the early return; replace each `try { await writeTextFile(path, next, body); settled = next; } catch { … }` write with `settled = await this.writeFlip(path, body, next, line, task, to)` keeping the existing catch → `next = null` fall-through to the re-read, and change the retry re-read to `readTextFile(path, { on: this.on })`. Nothing else in the function moves — optimistic flip, `settled`/`why`, revert, toast and `this.toggling` are unchanged.
- [x] 1.4 Open the gates in `taskLine`: drop `.when(!this.on, …)` around the row's click chain (keep `cursor_pointer().hover(…).on_click((_e, cx) => this.toggle(row, name, cx))` unconditional) and pass `(cx) => this.toggle(row, name, cx)` as the hover card's fifth argument for every task row. The section call site still passes nothing.
- [x] 1.5 Update the comments that state the old rule: `toggle()`'s ("local spaces only: writeTextFile takes no `on`"), `hoverCard`'s ("local spaces only", "Remote and section cards pass nothing and stay buttonless") and `taskLine`'s ("local rows click to tick").
